# NovelAI Writer — 重构后架构设计（v3）

> **版本:** v3.0（2026-08-18，LangGraph 多 Agent 重构）
> **前置:** v2 为 LangChain 直调伪 Agent + Mock MCP；本版为可插拔能力栈 + 真实编排

---

## 1. 分层架构

```
┌─ 展示层    Vue 3 + Naive UI（10 页面，类型化 SSE 消费）
├─ API 薄层   app/api/*（11 组路由，只做校验与调度）
├─ Service 层 app/services/*（项目/设定/写作/审核/知识库，事务边界）
├─ 编排层    app/agents/*（LangGraph: NovelState / GraphEvent / GraphRunner / 4 图 / 节点）
├─ 能力层    app/core/*（llm / tools / search / knowledge / mcp / skills）
└─ 数据层    SQLAlchemy 16 表 + Alembic + Chroma 向量库
```

依赖方向单向：`api → services → agents(graphs/nodes) → core → models`

## 2. LangGraph 编排（核心）

| 图 | 节点流 | 特性 |
|:--|:--|:--|
| setting_graph | assemble → 路由(kind) → generate_{7类} → consistency_check → persist | 生成自动入库 |
| chapter_graph | retrieve_context(知识注入) → write_draft(流式/ReAct工具) → review_draft → **rewrite 循环**(≤max, 阈值门) → persist | 工具循环 + 重写反馈 |
| review_graph | split(Send 并行 8 维) → review_dim → aggregate | 并行审核聚合 |
| chat_graph | supervisor(LLM 分类优先+TTL缓存 + 关键词回退) → 路由子图 | 自由文本入口 |

- **State**: `NovelState`（TypedDict + Annotated add reducer for events/reviews）
- **事件协议**: node_start/node_end/token/tool_call/tool_result/review/checkpoint/done/error
- **运行追踪（G4）**: GraphRunner 每次运行写 `agent_runs` 表（graph/status/input/output/**events_data 压缩时间线**）；`/api/agents/runs/{id}` 返回节点耗时/token 统计/事件流（前端「运行记录」页可视化）
- **技能合并（G2）**: 请求级与项目级（Project.skill_packs）并集去重，请求优先；`skills=[]` 显式禁用项目级；`skills=None` 使用项目级
- **流式**: `app.astream(stream_mode=["updates"])`，节点自行产出事件；token 由节点 emit（供应商无关，Mock 亦流式）

## 3. 能力层设计

### llm（多供应商）
- `LLMProvider` 抽象（acomplete/astream/bind_tools/with_structured）
- `openai-compat` 万能适配器（deepseek/qwen/glm/kimi/mimo… 均走 ChatOpenAI + base_url）
- 专用: anthropic / gemini / ollama / azure；`mock` 确定性降级
- 工厂: 注册表驱动 + 自动降级（无 Key → mock）+ `provider:model` 请求级覆盖

### tools（注册表）
- `BaseTool`（name/description/args_schema/execute→ToolResult）
- 10 内置: web_search / setting_query / chapter_get / project_summary / character_lookup / weapon_lookup / world_setting_lookup / foreshadow_query / knowledge_retrieve / hot_meme_lookup
- 双向桥接: 内部→LangChain tools / MCP 暴露；外部 MCP 工具→`mcp_<server>_<tool>`
- 图级白名单（writer 图绑定写作相关工具）

### search（多后端降级）
- SearchProvider 抽象 + router（tavily/duckduckgo/bing/searxng/bocha/mock）
- auto 模式按可用 Key 降级；统一缓存

### knowledge（知识库）
- 存储双轨: 结构化（16 表：角色/兵器/世界观/热梗…）+ 文档（knowledge_docs/chunks + 向量）
- 索引: 段落优先切片 → embedding（openai/mock）→ 向量存储（I1 三后端可选）
- 检索: 关键词 ILIKE（CJK 二元组 OR）∪ 向量 TopK 混合；结果 TTL 缓存（H3），写操作显式失效
- 向量后端: chroma（默认）/ **local（I1: numpy 余弦暴力检索 + JSON 持久化，无外部依赖）** / mock（内存）
- CRUD: 文档/热梗 增删改查齐备（I3: PUT 更新文档自动重索引+缓存失效）

### mcp（双向）
- 服务端: MCPServer + 注册表自动暴露（代码生成带类型签名 handler），stdio/SSE
- 客户端: 按 config/mcp_servers.yaml 桥接外部 server（工具命名 mcp_<name>_<tool>）
- **连接池（G3+I2 参数化）**: 每 server 长连接会话池（惰性建连、跨调用复用、失效自动销毁重建重试）；条目可选 pool_size（stdio 强制 1 / SSE 可 >1 并发）、connect_timeout、max_retries，缺省取 MCP_DEFAULT_*；应用退出/`/api/mcp/reload` 时管理

### skills（技能包）
- 格式: skills/<name>/SKILL.md（frontmatter: name/description/version/tools/knowledge_refs/enabled + 正文）
- 注入: system prompt 追加 + 工具白名单合并（请求级 state.skills；G2 并集策略: None→项目级、[]→显式禁用、非空→请求优先去重）
- **管理（H4）**: SkillManager 文件 CRUD（写入首目录 + 刷新全局注册表）+ `/api/skills` POST/PUT/DELETE/PATCH enabled + 前端技能包管理页（/skills）
- 内置 6 包: webnovel-standards / character-arc / foreshadow-manager / pacing-control / prose-polish / genre-xuanhuan

### cache（通用 TTL 缓存层，H 轮）
- `TTLCache`（线程安全、LRU 上限、惰性过期、返回深拷贝防污染）+ `memoize_async` 装饰器
- 消费方一: supervisor 意图分类（AGENT_LLM_SUPERVISOR_CACHE/TTL，相同任务免重复 LLM 调用，成本门控）
- 消费方二: 知识检索结果（KNOWLEDGE_CACHE_ENABLED/TTL，按 query/project/top_k/categories/memes 键控；知识库/热梗写操作主动失效）
- **可观测（J 轮）**: 命中/未命中/淘汰计数；`/api/cache/stats` + `/api/cache/clear`；全局设置页运行时缓存卡

### 可观测性（J 轮）
- MCP 连接池 `status()`（transport/pool_size/会话数/忙闲/超时/重试/closed/last_error/connected_at）→ `/api/mcp/servers` 返回配置+实时池状态，全局设置页展示
- `/api/runtime/config` 脱敏有效配置（llm/search/embedding/vector_store/mcp/agent/skills）→ 全局设置页运行时配置卡

## 5. 关键决策记录（ADR 摘要）

- D1 保留 FastAPI+Vue3+SQLite，引入 Alembic + Chroma
- D2 LangGraph v1（兼容 langchain-core 1.5.x；astream updates 模式 + 节点自产事件）
- D3 OpenAI 兼容万能适配器覆盖绝大多数供应商
- D4 服务层切图执行（单一执行路径，旧 Agent 全部退役）
- D5 知识库结构化复用现有表，文档型走向量化
- D6 MCP 包移入 app/core/mcp 避免与 SDK 包名冲突；启动入口 `python -m app.core.mcp.server`
- D7 技能为请求级注入（项目级绑定留待后续）
- D8 运行时热点缓存收敛到 app/core/cache（分类/检索共用一套 TTL 语义；写路径显式失效而非短 TTL 兜底）
- D9 向量后端可插拔且含无依赖的 local 实现（numpy 暴力检索 + JSON 持久化）：测试/离线/小规模场景免装 chromadb
- D10 运行记录可清理（单条删除 + 按项目/图清空，未限定范围拒绝——防误删审计数据）
- D11 可观测性内建：缓存计数、MCP 池状态、脱敏运行时配置端点——排障免翻日志/代码
- D12 显式配置值优先于默认（修复 `0 or default` 吞掉 max_retries=0 的问题：显式 0 不再回落默认）
