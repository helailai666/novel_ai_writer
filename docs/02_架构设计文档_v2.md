## 2. Agent 详细设计（6个Agent）

### 2.1 Master Agent（主控智能体）
- **职责:** 协调整个创作流程，管理状态流转
- **工具:** 调用其他5个Agent、项目管理
- **记忆:** 项目级别长期记忆（SQLite）
- **输入:** 用户指令 + 当前项目状态
- **输出:** 下一步行动指令、进度报告

### 2.2 Creative Agent（创意智能体）
- **职责:** M1-M12所有设定的生成与优化
- **工具:** 调用Search Agent获取参考、生成设定卡片
- **记忆:** 12大模块设定数据（SQLite + VectorStore）
- **特色:** 支持多方案对比、灵感碰撞

### 2.3 Writer Agent（写作智能体）
- **职责:** 章节内容生成
- **工具:** 检索所有设定 + 前文 + 伏笔
- **记忆:** L1-L5分层记忆策略
- **特色:** 流式输出，自动标注元数据

### 2.4 Review Agent（审校智能体）
- **职责:** 一致性检查、伏笔回收验证、语法修正
- **工具:** 跨模块设定比对、伏笔追踪
- **输出:** 修改建议 + 不一致问题列表 + 伏笔回收报告
- **特色:** 支持人工审核门（Human-in-the-loop）

### 2.5 World Agent（世界维护智能体）— 🆕 新增
- **职责:** 所有12个设定模块的一致性维护和冲突检测
- **工具:** 跨设定关联分析、版本管理
- **功能:** 
  - 当修改某个设定时，自动检测与其他模块的冲突
  - 生成冲突报告和修改建议
  - 维护设定的版本历史

### 2.6 Search Agent（搜索智能体）— 🆕 新增
- **职责:** 网络搜索参考信息，辅助设定生成
- **工具:** Tavily / Bing搜索 / 网页抓取
- **场景:**
  - **小说参考:** 用户输入小说名 → 搜索该小说的类型/设定/角色/世界观
  - **设定参考:** 如"搜索唐朝官制" → 辅助历史类设定
  - **灵感获取:** 搜索热点题材/流行元素
- **输出:** 结构化搜索结果 → Creative Agent消化后生成设定

## 3. 搜索智能体工作流程

```
用户输入: "帮我分析《凡人修仙传》"
    ↓
Search Agent 启动
    ├── 搜索1: "凡人修仙传 小说类型 + 世界观"
    ├── 搜索2: "凡人修仙传 主角 + 能力体系"
    ├── 搜索3: "凡人修仙传 等级境界体系"
    ├── 搜索4: "凡人修仙传 主要势力"
    └── 搜索5: "凡人修仙传 剧情大纲"
    ↓
搜索结果聚合 & 结构化
    ├── 类型: 修仙/仙侠
    ├── 世界观: 人界→灵界→仙界 三界体系
    ├── 境界: 练气→筑基→结丹→元婴→化神→...
    ├── 势力: 七玄门/掩月宗/魔道六宗
    └── 主角: 韩立(凡人资质/谨慎/多宝)
    ↓
Creative Agent 接收
    └── 生成项目初始化设定（用户可编辑修改）
```

## 4. 12大模块数据存储设计

| 模块 | 存储方式 | 关联数据 |
|:----|:--------|:--------|
| M1-基础设定 | Project表字段 | 全局 |
| M2-世界观 | WorldSetting表 | 关联Project |
| M3-角色 | Character表 + CharacterRelation表 | 角色间关系网络 |
| M4-能力 | Skill表 + SkillTree表 | 关联角色 |
| M5-道具 | Item表 + ItemRecipe表 | 关联角色/场景 |
| M6-势力 | Faction表 + FactionRelation表 | 关联角色 |
| M7-大纲 | Outline表 + Volume表 + ChapterOutline表 | 全局 |
| M8-场景 | Location表 | 关联章节 |
| M9-时间线 | TimelineEvent表 | 关联章节/角色 |
| M10-伏笔 | Foreshadow表 + ForeshadowTrack表 | 关联章节 |
| M11-元数据 | ChapterMeta表 | 关联章节 |
| M12-多卷 | VolumePlan表 | 关联项目 |

## 5. 技术选型（更新版）

| 组件 | 推荐 | 说明 |
|:----|:----|:----|
| 前端 | Vue 3 + Naive UI | 设定卡片/关系图/编辑器 |
| 后端 | FastAPI | 异步+WebSocket |
| AI框架 | LangChain 0.3+ | Agent/Chain/Tool |
| 数据库 | SQLite → PostgreSQL | 12模块关系型数据 |
| 向量库 | FAISS | 设定语义检索 |
| 搜索API | **Tavily** (首选) | **新增** AI优化搜索 |
| 搜索备选 | Bing Search API | **新增** 备用 |
| LLM主力 | GPT-4o-mini | 性价比 |
| LLM本地 | Ollama | 离线使用 |
