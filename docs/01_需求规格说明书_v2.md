# NovelAI Writer — 需求规格说明书（完善版）

> **版本:** v2.0  
> **日期:** 2026-06-02  
> **项目:** 基于 LangChain 的 AI 写小说智能体

---

## 1. 项目概述

### 1.1 项目背景
利用 AI 大模型能力，遵循专业小说创作流程，分阶段、系统化地辅助用户完成长篇小说创作。

### 1.2 项目目标
开发一套基于 LangChain Agent 架构的 AI 写小说工具，支持完整的小说创作工作流，并具备 Web 管理页面。

## 3. 创作工作流（7步完整流程）

```
Step 1: 创建项目 + 选择类型/风格
    ↓
Step 2: 世界观搭建（背景/规则/种族/历史）
    ↓
Step 3: 角色设计（主角/配角/反派 + 关系网络）
    ↓
Step 4: 能力体系 + 道具体系设定
    ↓
Step 5: 大纲生成（主线/分卷/章节/伏笔）
    ↓
Step 6: 逐章写作（含场景/道具/出场角色元数据）
    ↓
Step 7: 审校修订（一致性/AI审校/人工审核门）
```

**每一步都可回退修改，且修改后自动通知下游步骤。** 例如修改角色设定后，已生成的章节中该角色相关内容会被标记为"需重新审校"。

## 5. AI 智能体升级设计

| Agent | 职责 | 新增能力 |
|:-----|:-----|:--------|
| **Master Agent** | 协调流程 | 跨模块一致性检查 |
| **Creative Agent** | 设定生成 | 道具体系/势力关系/伏笔设计 |
| **Writer Agent** | 内容生成 | 出场角色标注/道具使用追踪 |
| **Review Agent** | 审校 | 伏笔回收检查/设定一致性验证 |
| **✨ World Agent** (新增) | 世界观维护 | 所有设定的版本管理、冲突检测 |
